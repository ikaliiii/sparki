## How to Read This Site

- **Observed:** directly recorded evidence.
- **Verified context:** supported background or constraints.
- **Prototyped:** represented in a draft or testable artifact.
- **Illustrative:** a plausible example, not a result.
- **Hypothesis:** a claim still needing evidence.
- **Pilot target:** a planned test or outcome.
- **Unresolved:** an open question.
