<span class="sparki-meta">PILOT TARGET</span>

Measurement should show whether intent produces comprehension, reciprocal interest, consented introductions, and useful outcomes.

## Funnel Signals

- Comprehension
- Reciprocal Interest
- Need More Information
- Pass reasons
- Constraint resolution
- Remediation
- Introductions
- Defined next actions

## Outcome Windows

- Day 7 outcomes
- Day 21 outcomes
- Return behavior

## Measurement Rule

Record the event, timestamp, actor, reason, and next action. Do not convert an activity count into a success claim without a defined denominator and follow-up window.

Baseline values and target thresholds are unresolved.
